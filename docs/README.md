# Cerul documentation

Cerul is a local video processing core and CLI. Start with the user guides to
install it, search your own videos, and work with LeRobot datasets.

Documentation on `main` follows the current source. For a released binary, select
its matching tag in the [repository](https://github.com/cerul-ai/cerul/tags) before
reading command or compatibility details.
