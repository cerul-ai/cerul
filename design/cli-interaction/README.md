# CLI interaction design

These notes preserve the design rationale for terminal and agent interaction.
They are not a second command reference or an implementation backlog.
[DESIGN.md](../../DESIGN.md) defines behavior; [user guides](../../docs/README.md)
and the [agent contract](../../docs/agent.md) describe supported use.

- [Terminal interaction](v2/COMMANDS.md): presentation principles and validation.
- [Agent mode](v2/AGENT-MODE.md): machine-interface and skill design decisions.

Earlier screen mockups, proposed defaults and implementation sequences remain
in [Git history](https://github.com/cerul-ai/cerul/blob/cce52298b3b594699ed45b4ce972c48acb6672f0/design/cli-interaction/v2/COMMANDS.md).
They may differ from the current CLI and do not depend on retaining a design branch.
